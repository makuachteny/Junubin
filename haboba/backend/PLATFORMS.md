# Platform Logins (Global Deployment)

Use these platform logins to deploy JuNubin globally:

- Render: https://dashboard.render.com/
- Railway: https://railway.app/dashboard
- Fly.io: https://fly.io/dashboard
- Neon (Postgres): https://console.neon.tech/app/projects
- Supabase (alternative Postgres + auth tools): https://supabase.com/dashboard
- Cloudflare (edge/CDN/WAF): https://dash.cloudflare.com/login
- Sentry (error monitoring): https://sentry.io/auth/login/

## Recommended minimal stack

1. Render (API)
2. Neon (database)
3. Cloudflare (edge + security)
4. Sentry (monitoring)

## Credentials

Account credentials are not generated in this repository. Sign in with your own email and set up team access + 2FA on each platform.
