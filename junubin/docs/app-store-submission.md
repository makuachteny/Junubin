# App Store Submission Checklist

JuNubin is a free South Sudanese Social Networking app. Submit it with no
in-app purchases, no premium tiers, no paid subscriptions, and no paid
consumables.

## App Information

| Field | Suggested value |
|---|---|
| Subtitle | `South Sudanese community` |
| Category (Primary) | Social Networking |
| Category (Secondary) | Lifestyle |
| Price | Free |
| In-app purchases | None |
| Privacy Policy URL | Host `docs/privacy-policy.md` |
| Support URL | Host your support/contact page |

## App Privacy

Declare data honestly based on the current app:

| Data type | Linked to user? | Used for tracking? | Purpose |
|---|---|---|---|
| Email address or phone number | Yes | No | Authentication, account management |
| Photos | Yes | No | Profile photos and verification |
| User content | Yes | No | Text messages, profile text, reports |
| Coarse location | Yes | No | Nearby discovery when user opts in |
| Identifiers | Yes | No | App functionality |
| Usage data | No | No | Product quality and diagnostics |
| Diagnostics | No | No | Crash and error diagnostics |
| Purchases | No | No | Not collected |

Do not declare payment information, purchase history, or in-app purchase data
unless the product direction changes.

## Age Rating

Recommended: 17+ because the app allows user profiles, user-generated messages,
location-based discovery, and user reports.

## Screenshots

Use screenshots from the current free social app:

1. Nearby people map/list.
2. Directory search and filters.
3. Profile detail with verification.
4. Message requests.
5. Text chat.
6. Profile privacy/settings.

Avoid screenshots of swipe decks, match celebrations, paid products, premium
badges, boosts, coins, or checkout screens.

## Description

Use copy like:

```text
JuNubin helps the South Sudanese diaspora find community wherever they live.
Discover nearby people who choose to be visible, search the diaspora directory,
follow profiles, send message requests, and chat after a request is accepted.

JuNubin is free. All discovery, messaging, profile, privacy, verification, and
safety features are available without payment.

Safety tools include photo verification, block, report, screenshot protection on
sensitive screens, and account deletion.
```

## Review Notes

Tell reviewers:

```text
JuNubin is a free Social Networking app for the South Sudanese diaspora.
There are no in-app purchases, premium tiers, subscriptions, paid boosts,
coins, Super Likes, or checkout screens.

The app uses OTP sign-in. Please use the provided review account and OTP
instructions. The main flows to test are onboarding, profile editing, directory
search, nearby discovery, message requests, chat, photo verification, block,
report, and account deletion.
```
